# 快速上手指南：緊急任務報修紀錄系統

## 1. 開發環境設置
*   **Node.js**: v18+
*   **PostgreSQL**: v14+
*   **套件安裝**: `npm install` (於專案初始化後)

## 2. 測試流程
*   執行單元測試: `npm test`
*   驗證 API 契約: 查看 `/contracts/api.md` 並對照 Postman/Insomnia 集合。

## 3. 核心功能驗證
1.  **CS 報修**: 登入 CS 帳號 -> 輸入卡號/分機 -> 提交。
2.  **主管稽核**: 登入 Supervisor 帳號 -> 查看儀表板 -> 點擊匯出。

## 4. 語言規範提醒
本專案嚴格要求正體中文。所有開發日誌與 UI 文字請務必遵循憲法 v1.2.0。
